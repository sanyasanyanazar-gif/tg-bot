# 🤖 Умный Помощник для Telegram Канала

Полностью автоматизированный бот для сбора контактов подписчиков и отправки рассылок.

## 📋 Функции

✅ Сбор контактов - подписчики добавляют свои данные
✅ База данных - автоматическое сохранение
✅ Рассылки - отправка новостей
✅ Статистика - просмотр количества контактов
✅ Админ панель - управление ботом
✅ Экспорт - сохранение контактов в CSV

## 🚀 Быстрый старт

1. Создайте бота в @BotFather
2. Загрузите код на Render
3. Готово! Бот работает 24/7

## 📱 Команды

- /start - Начало
- /help - Справка
- /admin - Админ панель
- /stats - Статистика
